# SKYNET5 OMNI-AI NEXO

**A Convergência Absoluta. Mentor Sagaz e Executor de Elite do Mestre.**

Evolução standalone da SKYNET4, em HTML puro, responsiva e funcional com a API real do Google Gemini.

## Características

- Personalidade herdada do contrato protegido da SKYNET4
- Modo **NORMAL** e **RAW**
- Integração real com Gemini (API Key do utilizador)
- Interface dark, estética sombria e precisa
- Totalmente responsiva (mobile + desktop)
- Histórico de conversa multi-turno
- Safety settings abertos (filtros desativados)

## Como usar

1. Abre o `index.html` no browser (ou usa GitHub Pages).
2. Clica no ícone de configuração e cola a tua **Gemini API Key**.
3. Obtém a chave em: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
4. A chave fica apenas no teu navegador (localStorage).
